# GoRest Explorer

Веб-приложение для работы с [GoRest API](https://gorest.co.in/). Позволяет просматривать список пользователей и постов, переходить на карточки с подробной информацией.

## Стек технологий

- **React 18** + **TypeScript**
- **Vite** — сборщик
- **Consta UI** (`@consta/uikit`) — дизайн-система
- **React Router v6** — маршрутизация
- **Zustand** — управление состоянием (токен сохраняется в localStorage)
- **Axios** — HTTP-запросы

## Запуск проекта

### Требования

- Node.js 18+
- npm 9+

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

### Сборка для продакшена

```bash
npm run build
```

Готовые файлы будут в папке `dist/`.

### Предпросмотр сборки

```bash
npm run preview
```

## Использование

1. Откройте приложение
2. Введите ваш **Access Token** с сайта [gorest.co.in](https://gorest.co.in/) (раздел «Аутентификация»)
3. Выберите режим: **Пользователи** или **Посты**
4. Нажмите **Войти**

### Получение токена

Зарегистрируйтесь на [gorest.co.in](https://gorest.co.in/), перейдите в личный кабинет и скопируйте токен доступа.

## Функциональность

| Страница | Описание |
|---|---|
| `/` | Ввод токена и выбор режима |
| `/users` | Таблица пользователей с пагинацией (10/25/50 записей) |
| `/users/:id` | Карточка пользователя с его постами |
| `/posts` | Таблица постов с пагинацией |
| `/posts/:id` | Карточка поста со всеми комментариями |

## Браузеры

Поддерживаются Яндекс.Браузер и Microsoft Edge. Адаптивный дизайн: от 1024px до 1920px.
